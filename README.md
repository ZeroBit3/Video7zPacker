# Auto 7z Interactive Packer

这是一个基于 Python 的自动化分卷加密打包工具。它通过调用系统底层的 7-Zip 命令，自动识别视频集数，并将大文件进行动态、不规则的分卷加密压缩。

## ✨ 功能特性

- **交互式与静默配置**：支持运行时自动询问密码和输出路径，也支持通过 `config.ini` 读取静默配置，实现无人值守批量处理。
- **智能特征识别**：自动清理文件名中的干扰项（如分辨率、编码格式等），精准提取视频集数（如 E01, 第1集），并以此自动命名压缩包。
- **动态不规则分卷**：当文件超过设定阈值（默认 1.8GB）时会自动触发分卷。程序会为**同一个文件的每一个分卷**生成随机的大小（在 1.65GiB 到 1.8GiB 之间动态浮动）。引入动态大小有助于增加文件体积特征差异，同时规避部分网盘或文件系统的限制。
- **安全加密与存储**：使用 7z 格式存储（`-mx=0` 仅存储，无损不压缩提高速度），并开启强制文件名加密（`-mhe=on`）。
- **冲突处理机制**：遇到同名文件时，支持通过配置或交互提示来自动清理旧文件并重新打包。

## 🛠️ 环境要求

1. **Python 3.x**：脚本仅依赖 Python 内置模块，无需使用 pip 安装额外包。
2. **7-Zip**：系统必须已安装 7-Zip。程序会自动寻找默认路径 (`C:\Program Files\7-Zip\7z.exe`) 或环境变量中的执行文件。

## 🚀 使用方法

将需要打包的视频文件（支持 `.mp4`, `.mkv`, `.avi`, `.iso` 等主流格式）放置在脚本同级目录下，然后在终端运行：

```bash
python Pack_7z.py
```

## 注意事项

- 脚本默认在当前目录下扫描视频文件。
- 确保输出目录有足够的写入权限。
- 脚本目前处理 .mp4, .mkv, .avi 等主流视频格式及 .iso 文件。
